# HubSpot staging v1\n\nThis branch is isolated from production. Run `npm test`, then `npm start`. Requires Node 20+, HubSpot private-app token with contacts and notes read/write scopes, and STAGING_API_KEY. POST /api/intake with JSON {email,firstName,lastName,enquiry}, headers x-api-key and idempotency-key (16–128 alphanumeric/underscore/hyphen characters). Existing contact is located by exact normalized email; a new enquiry is attached as a HubSpot note. Zero matches creates a contact; multiple matches stop for review. This is **not production ready**: in-memory idempotency resets on restart, no distributed locking, no database audit, no per-tenant OAuth, and no reconciliation for partial writes. Do not connect real customer data until these gaps are resolved. Never place the API key or HubSpot token in a public browser client.\n
